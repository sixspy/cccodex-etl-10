# cc-etl-lab

CC_Codex 二期（26.11）**数据工程**产品线：**抽取转换加载台**（FastAPI + Vue 3 SPA + SQLite）。

与 `cc-data-lab`（Flask + HTMX 采集控制台）错开：本线面向 **ETL 管道编排 / 抽取落库**，前端为 Vue 单页，暖色仓运风格。

## 领域

- **所属领域**：数据工程  
- **子方向**：抽取-转换-加载 / 数据采集与落库  

## 技术栈

| 层 | 选型 |
|----|------|
| 后端 | Python 3.12、FastAPI、Uvicorn、SQLite |

## 基线能力

登录、管道列表、管道详情、执行抽取、执行落库。后续单轮题在此叠加增量水位、清洗口径、并发争用、跨日重算等。

## 分区落库与回溯窗

分区写入一律由服务端裁决，前端只负责把占用板与裁决结果画清楚。

- **分区占用板**：列出每个分区的分区键、行数、是否在窗内、策略名、占用状态与累计写入笔数。
- **回溯策略（本日锁死）**：
  - `固定窗重落`：钉死一个正整数天数，只允许重落最近 N 天的窗内分区，窗外重落拒绝。
  - `先清空再写`：允许任意历史分区，但必须整分区先清空再写。
  - 策略选定后当日锁死，次日才可改；重落手法与策略漂移即判「回溯策略写歪了」。
- **服务端裁决规则**：
  - 分区键为空直接失败，不留占用。
  - 同一分区两人同刻落库只成一笔，后来者记抢占失败（应用层检查 + 数据库部分唯一索引双保险）。
  - 今日分区正在写入时，禁止开启任何回溯。
  - 重落成功后管道总览可看出分区已重写（重写计数、写入笔数、窗内/窗外标记）。
- **回溯详情**：每笔落库、重写、清空、拒绝、抢占、回滚均落事件表，可读清空/拒绝原因与抢占记录。
- 写入支持一键落库与「开始写入 → 提交/回滚」两阶段，回滚不落任何数据并释放占用。
